- [ ] Run `pip install -r requirements.txt`.

## Demo explanation (short)
"FocusGuard AI is a Python-based desktop application that uses OpenCV and MediaPipe to process webcam frames. It estimates posture using pose landmarks and eye openness using face landmarks. CustomTkinter provides the dashboard, SQLite stores session summaries, and Matplotlib displays focus-score trends. It is an educational prototype and does not store webcam images."

## If the teacher asks what is unique
"It combines posture reminders, eye-state reminders, study-session tracking, local data storage, and visual analytics in a single desktop application."

## Important
Do not claim that the app scientifically measures concentration or diagnoses eye fatigue. Demonstrate the actual features that work on your laptop.
